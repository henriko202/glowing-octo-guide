## Assessed, not worth doing (recorded so nobody re-audits)

- **`vitest` 5.0.0 major bump.** Released 2026-09-03 (seven days before this review); no security or EOL driver, and it
  is a three-workspace test-runner change. Revisit as a batched upgrade. Within v4 the lock is one patch behind
  (4.1.11); a normal `pnpm update` handles it.
- **New Convex components not in use.** `@convex-dev/aggregate` (counts are already denormalized and correct),
  `@convex-dev/migrations` (the hand-rolled backfills are idempotent, bounded and self-rescheduling pre-launch),
  `@convex-dev/presence` (no presence feature exists), `@convex-dev/agent` (AI features are single-shot calls, not
  durable conversations). Direction option 2 covers the one case worth revisiting (`workpool` for the manual fan-out).
- **`convex` 1.41 to 1.45.** Four minors behind; no source uses an API newer than 1.41. Routine bump, folded into D5
  rather than its own finding.
- **Admin `listUsers` reactive over 1000 rows.** Admin-only, tool surface, invalidated infrequently (login patches). Not
  worth de-reactivating now.
- **`shadcn` CLI listed under app runtime dependencies (`app/package.json:32`).** Install-surface bloat, not a security
  defect.

## Direction (grounded options, not findings)

1. **Convex-native auth later.** No `convex/auth.config.ts` exists; the opaque-session stack is a
   deliberate design. A future phase could register LinkedIn as an OIDC provider and move identity to
   `ctx.auth.getUserIdentity()`, deleting much hand-rolled surface. Large effort, touches every
   protected function; do it after the S fixes.
2. **Component adoption where the code hand-rolls documented patterns.** `@convex-dev/workpool` for the
   manual fan-out/batching (`lib/concurrency.ts`, Apify jobs) and `@convex-dev/aggregate` for
   recap/survival/history counts would remove the C5-C8 read-amplification class. Medium effort.
3. **Encode doc-claim drift in CI.** D10 lists security-relevant facts that drifted despite the
   AGENTS.md keep-in-sync rule. A small script that asserts the few constants named in PLATFORM.md (session TTL, caps)
   would catch this class.

## Scope and method

- Covered: `convex/` (77 non-test files, 165 registrations), `app/src`, `landing/`, HTTP routes,
  package manifests, env examples, headers/CSP generation.
- Not covered: live deployment insights/advisor telemetry (MCP unavailable), `pnpm audit`/CVE database,
  runtime test execution.
- Clean per the sweep: every public function resolves identity server-side; no IDOR found; no
  client-supplied identity trusted; schedulers/crons target `internal.*`; no committed `.env.local`;
  Stripe signature verification and price allowlists in place; SSRF allowlists hold on the shortener
  hops; PostHog consent gating and Sentry masking are real; app CSP hash logic checks out.
