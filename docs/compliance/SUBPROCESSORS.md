# Sub-Processor List

**Controller:** [LEGAL_ENTITY_NAME]
**Service:** Link Into The SSI

This document lists all third-party organisations that process personal data on behalf of Link Into The SSI as data controller. It is maintained in accordance with GDPR Art. 28(3)(e) and equivalent obligations under UK GDPR, LGPD, and applicable US state law.

> **Note on Apify:** Apify is **NOT a current sub-processor.** The LinkedIn post-sync and profile-scrape integrations that use Apify are **dormant and disabled at launch** (kill-switch flags in `appSettings`; `APIFY_*` environment variables unset; no active cron triggers). Apify must be added to this list — and a signed DPA obtained — **only if those integrations are enabled in production.** See `DATA-INVENTORY.md` §6 (Dormant Integrations) for the HARD GATE requirements that must be completed before enabling Apify.
